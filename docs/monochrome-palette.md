# Baba Hakeem — Monochrome Design Palette

Design decision: the website's UI uses **white, grayscale and black only**. All decorative green, sage, cream/gold, red and tinted UI accents have been converted to neutral luminance-matched grays, including cart, checkout, premium order receipt, admin reports and inventory controls, product pages, nav, global storefront styles, and contact form statuses.

## Scope
- UI CSS color values (hex, RGB, HSL): neutral grayscale with original opacity preserved.
- Two JSX inline UI styles: ContactEnquiryForm and AdminEnquiries.
- All other styling properties are unchanged: sizes, position, spacing, transforms, filters, responsive breakpoints, shadows' offsets, and animation curves/timings.
- The project's own image assets, uploaded product photos, GSAP 3D models, inline canvas-generated product artwork and physical packaging colors are deliberately **not** recolored. User asked to change the **website theme**, not the colors of items sold.
- No Supabase data, credentials, payment logic, order handling, shipping, admin permissions or database schema modifications.

## Verification checklist
1. Homepage: premium light/gray/black UI, product imagery retains natural colors. Header, GSAP bottle-to-hands, rotating product cards and scroll choreography must remain intact.
2. Cart: neutral progress stepper, black/gray buttons, readable products and order summary, no new green.
3. Checkout: neutral form fields and COD confirmation, all original delivery details and validated order submission.
4. Thank You: charcoal/black receipt (previously emerald green), gray progress card and clear pending-order messaging.
5. Admin: dark charcoal sidebar, white/gray status cards, reports, order operations and contact inbox.
6. Product details, About, Contact and other legal/editorial pages: neutral accent styling and original legibility.
7. Mobile at 390px and tablet at 768px: no horizontal clipping.
8. Regression checks include CSS-wide achromatic color audit; product photography must not be altered.
9. Real COD order/email delivery should not be assumed tested based on a successful build.

## Developer note
This monochrome conversion adjusts explicit CSS colors, **not** images, nor WebGL/canvas product art generated by JS. Legacy style comments may mention old colors without having runtime effect. The source code of animations and commerce logic has not been modified.
