# Herbal Botanics

Immersive herbal e-commerce concept built as a senior-review demo.

## Stack
- Next.js 14
- GSAP + ScrollTrigger
- Lenis smooth scrolling
- Responsive CSS
- Demo cart interaction

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes
This is a fictional demo brand. Product names, claims and prices are for presentation only.
